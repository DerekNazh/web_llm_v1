## 项目优势

- 账号负载均衡+bit浏览器绑定ip/账号/设备指纹，防止平台风控封禁风险
- 每个大模型脚本匹配一个模型状态记录器，动态记录脚本的调用次数和成功率以及成功平均响应时间。
- 策略计算器动态分析所有脚本通过贝叶斯算法选取最佳模型。
- 通过**自定义异常继承体系**抛出给到**账号管理层，策略计算器层，模型状态记录器层，用户层**做相应处理。

## 项目准备

*需要下载bit浏览器，和配置账号管理池(mysql表)*

## 使用方式

*项目入口为task_executor.py的start_up_ai_server()，无需传参，可在此文件中自行配置启动ip和端口，以及接口路径*
